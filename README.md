# Semantic Topomap Display

This repository hosts a compact GitHub Pages presentation for the semantic topomap output.

## Pages

- `docs/index.html`: entry page
- `docs/nav_graph_visualization_3d.html`: 3D navigation graph
- `docs/object3d_global_map.html`: Object3D global map

## GitHub Pages

Enable Pages with:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

The site will be available at:

```text
https://mizhiaishang.github.io/display/
```

Large replay artifacts such as `.rrd`, `.svo2`, depth frames, and raw logs are intentionally excluded from this display repository.
