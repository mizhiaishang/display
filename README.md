# 项目展示

本仓库用于展示语义拓扑地图与 3D 物体全局地图结果。

## 在线文件

- `nav_graph_visualization_3d.html`：3D 语义拓扑导航图，可交互查看路径点、拓扑节点、语义区域和导航对象。
- `object3d_global_map.html`：3D 物体全局地图，可交互查看相机轨迹、物体位置和 3D bbox。
