# 基于语义世界模型的未知环境机器人自主探索系统

**项目时间：2025年12月 - 2026年06月**

本项目面向具身机器人在未知环境中空间理解不足、长期语义记忆缺失以及复杂任务难以自主执行等问题，设计并实现融合多模态感知、语义世界模型、空间推理和导航执行的自主探索系统，构建从环境感知、空间建模、任务规划到机器人行动反馈的完整闭环。

## 动态展示

![仿真场景动态展示](images/simulation_scene.gif)

 ROS2 + Gazebo + Nav2 仿真环境中的机器人自主探索与导航过程，包括语义建图、目标搜索、路径规划、状态反馈和可视化监控界面。

## 主要职责

负责系统总体方案与任务闭环设计，基于 ROS2 + Gazebo + Nav2 搭建未知办公场景下的服务机器人自主探索系统，实现自然语言指令解析、语义建图、目标搜索、导航执行与状态反馈闭环；在约 33.5m × 29.0m、152 个模型实例、21 类模型的仿真场景中完成验证。

## 技术难点

- **三维语义建图**：基于 GroundingDINO、SAM 和 RGB-D 深度反投影构建三维语义对象，融合 OpenCLIP 特征进行跨帧对象关联与语义记忆，统一维护对象位置、拓扑地点、访问记录和任务状态。
- **拓扑语义引导主动探索**：设计未知边界候选点生成与拓扑语义软引导评分策略，从占据栅格中提取未知边界并生成候选探索点，综合信息增益、路径代价、障碍风险、历史访问、失败惩罚和语义线索进行排序，使机器人能够在目标未知时优先探索更相关区域。
- **语言任务规划与导航执行**：实现“已知目标直接导航、未知目标主动探索、发现目标后切换导航”的状态机，并围绕 OpenClaw 构建“自然语言解析 - 能力约束 - 结构化任务 - 行为树/状态机 - Nav2 执行 - 结果回传”链路，拦截超出机器人能力边界的指令。

## 核心性能

- 在 5 类目标、25 组配对场景的对照实验中，相比纯几何 frontier，语义拓扑软引导策略将搜索成功率提升 20 个百分点（72% → 92%），平均目标发现时间、实际行驶距离和执行探索点数分别降低 32%、34% 和 36%，每轮重复访问次数由 2.08 次降至 0.72 次。
- 在 60 条多类型自然语言指令测试中实现不低于 95% 的解析准确率和任务下发成功率，并完成 27 个巡检任务点、31 个导航路径点及约 176m 巡检路线的搜索、导航、巡检和状态回传闭环。
